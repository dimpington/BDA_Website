# Overview

The first website was developed by Tim Berners-Lee at CERN during the
creation of the World Wide Web. By the end of 1990, Berners-Lee had
implemented the first web server and browser on a NeXT computer at CERN.

The website was hosted at info.cern.ch and documented the World Wide Web
project itself. It provided information concerning the principles of the
Web, available software, technical documentation, and other web servers and
resources as they became available.

The site formed part of the experimental infrastructure through which the
fundamental technologies of the World Wide Web were developed and
demonstrated. Public availability of the Web expanded during 1991 as its
software and documentation were distributed beyond CERN.

For catalogue purposes, the Bureau treats the historical website as a
Digital Object distinct from the physical NeXT computer that hosted the
first web server, the WorldWideWeb browser and editor, and the wider World
Wide Web software project.

# Preservation Note

The website accessible today at info.cern.ch should not be interpreted as
an uninterrupted instance of the original 1990 service.

By 2013, the first website was no longer available online in its original
historical state. CERN subsequently undertook a preservation project to
restore the website and associated digital assets connected with the birth
of the World Wide Web.

The restored website was returned to its historical address and remains
publicly accessible. The Bureau therefore records the object as an
institutional reconstruction rather than as an active legacy website
preserved continuously in situ.
