# Core Domain Entity

## Digital Object

The Digital Object represents the Bureau's primary domain entity.

Every Bureau activity ultimately relates to one or more Digital Objects.

Digital Objects may represent a wide variety of historically significant digital heritage including, but not limited to:

- Websites
- Personal Homepages
- Forums
- Bulletin Board Systems
- FTP Archives
- Web Directories
- Search Engines
- Flash Experiences
- Browser Games
- Software
- Digital Collections
- IRC Networks
- Gopher Sites

Additional Digital Object types may be introduced as required.

## Lifecycle

Digital Objects transition through defined operational states throughout their existence within the Bureau.

The lifecycle is documented separately in:

`docs/03_Content/Digital Object Lifecycle.md`

## Public Presentation

Digital Objects are presented to the public through approved FWX records exposed by the Bureau website.

The website represents a public interface to FWX rather than the complete archival system.
